# Java Programlama Dersleri & Algoritma Uygulamaları

Bu depo, Fırat Üniversitesi Yazılım Mühendisliği dersleri ve kişisel yazılım geliştirme sürecimde yazdığım Java kodlarını, temel algoritmaları ve mini projeleri içerir.

## 📌 İşlenen Konular
* **Veri Tipleri & Değişkenler:** `int`, `double`, `boolean`, `String`
* **Girdi / Çıktı İşlemleri:** `Scanner` sınıfı, `printf` ile formatlı çıktı
* **Karar Yapıları:** `if-else` mantığı, `.equals()` ile metin denetimi
* **Döngüler:** `for`, `while` ve `break` akış kontrolleri
* **Aritmetik Operatörler:** `%` (modulus), tam sayı bölmesi ve tür dönüşümleri (casting)

## 💻 Mevcut Mini Projeler
1. **Paket Tarayıcı (`IfElsePratik.java`):** Kullanıcı girdisine bağlı döngü ve tek/çift paket ayrıştırma algoritması.
2. **Güvenlik Giriş Paneli (`GuvenlikGirisi.java`):** 3 hatalı deneme hakkı tanıyan `while` döngülü brute-force koruma simülasyonu.
